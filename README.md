# Internship Tasks – Data Analysis Projects
Overview

This repository contains data analysis tasks completed as part of my internship. Each task focuses on analyzing real-world datasets using Python to extract insights, understand patterns, and support data-driven decisions.

The projects mainly involve:

- Data cleaning and preprocessing

- Exploratory Data Analysis (EDA)

- Visualization

- Business insights based on data

Tools & Technologies Used

- Python

- Pandas

- NumPy

- Matplotlib

- Seaborn

- Jupyter Notebook

Task 1: Customer Transaction and Behavior Analysis
Objective

To analyze customer transaction data and understand customer purchasing behavior.

Key Work Done

- Cleaned and prepared transaction data

- Analyzed customer spending patterns

- Identified frequently purchased products

- Studied customer behavior trends over time

Insights

- Identified high-value customers

- Observed purchase frequency and average spend

- Highlighted patterns useful for customer segmentation

Task 2: Super Store Final Dataset Analysis
Objective

To analyze sales performance and profitability of a super store dataset.

Key Work Done

- Analyzed sales, profit, and discount data

- Compared performance across regions and categories

- Identified loss-making products and segments

Insights

- Found top-performing product categories

- Highlighted regions with high sales but low profit

- Identified discount impact on profitability

Task 3: Web Traffic Analysis
Objective

To understand website traffic behavior and user engagement.

Key Work Done

- Analyzed traffic trends over time

- Studied user activity and session patterns

- Identified peak traffic periods

Insights

- Observed high and low traffic time frames

- Analyzed user engagement trends

- Provided insights to improve website performance
